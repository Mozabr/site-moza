# mozabr.com.br

Site da Moza Assessoria. HTML e CSS estáticos, sem build.

**Abrir o kit de seções** (o desenho aprovado):

```bash
python3 -m http.server 8000
# depois: http://localhost:8000/kit-de-secoes.html
```

**Publicar:** subir o conteúdo de `public/` para a raiz do domínio na Hostinger.
Nada mais. Sem compilar, sem instalar dependência.

Regras do projeto em `CLAUDE.md`.
